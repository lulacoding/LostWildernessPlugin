# Lost Wilderness Player Handbook

This is the main player entry page for Lost Wilderness: where to start, how the network is structured, and which guides to read next.

---

## What Lost Wilderness Is

Lost Wilderness is a long-term survival network built around shared history, a custom calendar, server-wide events, cross-server travel, and clan-driven conflict.

- **Survival** is the main home server.
- **Amplified** is the connected second world.
- **Portals** link the two worlds together.
- **Discord verification** controls access from the lobby into the network.

Always join through the main proxy entrypoint, not directly into an individual backend, so portals and server switching work correctly.

---

## Getting Started

| Step | What To Do |
| --- | --- |
| 1 | Join the server and spawn in the lobby |
| 2 | Run **/verify** in-game |
| 3 | In Discord, run **/verify &lt;your_name&gt;** |
| 4 | Return to the lobby teleporter |
| 5 | Enter Survival and arrive at the **spawn village (0,0)** |
| 6 | Talk to the Greeter NPC and choose your **class** in the Class Hall |
| 7 | Explore the village (calendar square, travel yard, shrine) and then follow a road out into the world |

If you are brand new, start with [Lobby and verification](lobby-and-verification.md).

## What Makes This Network Different

- A persistent calendar that gives the world shared history and named years
- World events that change danger, weather, visibility, and atmosphere
- Survival and Amplified connected by custom portals instead of isolated servers
- Clan systems built for long-term politics, alliances, and war
- A single verification flow that ties Minecraft identity to Discord identity
