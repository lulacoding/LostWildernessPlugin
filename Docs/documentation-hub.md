## Documentation rules

- **Section hubs** use unique filenames (for example `architecture-hub.md`, `player-handbook.md`) so graph views and quick open show clear titles—not many duplicate `index.md` labels.
- Follow [Development style guide](development/style-guide.md).
- After major features: update `CHANGELOG.md`, [Implementation status](roadmap/implementation-status.md), and the relevant guide.
- Legacy V1-only docs are in [archive/](archive/archive-hub.md).
