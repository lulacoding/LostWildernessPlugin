# Lost Wilderness Design Bible

Part of the [Lost Wilderness documentation hub](../README.md). This section is the long-form concept and architecture source for the network: vision, lore, systems, worlds, technical intent, and unresolved design questions.

---

## How To Use This Section

- Use this folder for the intended shape of the project, not just the code that exists today.
- Use [implementation-status.md](../implementation-status.md) when you want the current live state.
- Use [roadmap.md](../roadmap.md) when you want the prioritized next steps.
- Treat the pages here as canonical design direction unless a status or changelog entry says the implementation differs.
