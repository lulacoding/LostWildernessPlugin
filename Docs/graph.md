# Graph View

This page is optimised for exploring the full documentation graph.

**How to use (Obsidian / compatible viewers):**
1. Look at the **Graph** panel in the right sidebar
2. Click the **dotted circle icon** ( ⊙ ) on the graph panel to switch from local → **global graph**
3. Drag, zoom, and click nodes to navigate

> [!tip] Shortcut
> You can also press `G` anywhere in the docs to toggle the full graph overlay.
